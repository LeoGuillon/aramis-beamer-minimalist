# `Aramis` $\LaTeX$ beamer template

A minimalist beamer template made for Aramis lab’s fellows.

This theme is made to provide both a theme, colors and fonts as well as a presentation boilerplate with an appropriate filestructure to easily navigate in your presentation files, either plots, graphs or slides.

## Dependancies

Mandatory :

- $\LaTeX$ distribution including `beamer` ;
- [LuaTeX](https://www.luatex.org/) or [XeTeX](https://xetex.sourceforge.net/), for proper fonts management. You can still build without, but expect bases beamer fonts, that will not fit the theme well.
- PGF/TikZ

Optional :

- `just` and `pandoc` to easily convert slides to another format, most notably `.ppt` format.

## Installation

You can use this theme by different methods, depending on your workflow :

Code editor + Git integration :

1. Click on "Use this template", then "Create a new repository" ;
2. Clone your newly created repository on your machine, and start working on your slides in `main.tex` file !

Code editor without Git integration :

1. Click on "< >Code", then "Download ZIP" ;
2. Extract the resulting `.zip` file on your machine, and start working on your slides in `main.tex` file !

[Overleaf](https://overleaf.com) :

1. Click on "< > Code", then "Download ZIP" ;
2. In Overleaf, click on "New Project", then "Upload Project", then select or drag the theme's .zip file.
